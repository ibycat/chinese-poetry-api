01快速开始

无需注册、无需 Token，直接 GET。

# 一个词就是一个分类
curl "BASE/shanshui.json"
curl "BASE/lushan.json"
curl "BASE/meihua.json"

# 多个分类：逗号分隔，等概率各占一份
curl "BASE/shanshui,lushan.json"
curl "BASE/songbie,shanshui,youxian.json?n=3"

# 全库随机
curl "BASE/all.json"

# 连续两句：全库 / 指定多个分类
curl "BASE/line"
curl "BASE/line.json?n=3"
curl "BASE/line/songbie,jizeng.json"

# 纯文本 / 图片
curl "BASE/aiqing.txt"
curl "BASE/meihua.svg"

把 BASE 替换为上方地址即可。浏览器直接打开同样可用。

04参数与格式

格式说明
.json默认结构化返回，含全文与标签
.txt普通模式仅返回正文；摘句模式统一返回 JSON，.txt 后缀也被忽略
.svg图片，可直接 <img src>
参数说明
n返回条数，大于 1 时返回数组。全库 1–50；分类与多选最多 20

分类全部写在路径里：

"BASE/shanshui.json"          # 一个大类
"BASE/lushan.json"            # 一个小类，不用带父级
"BASE/shanshui,lushan.json"  # 两个分类
"BASE/songbie,shanshui.json"

多选时先等概率选一个分类，再在该分类内选作品，所以语料多的分类不会挤占语料少的分类 （实测 /shanshui,zhiwu 各约 50%）。选中的分类可在返回体的 category / categories 里核对。

所有 slug 全局唯一，路径里只用 ASCII。题材为避开与意象分类重名， 用全拼或核心词区分：山水田园 /tianyuan、爱情相思 /xiangsi、 悼亡挽歌 /wange、哲理悟道 /wudao。完整清单见 /api。

摘句不会改变分类、全文和标签。每首先按标点切成小句，再顺序两两成组； 长诗、长词因此有多个句对参与随机，不会永远只看开头两句。整首作品先被等概率选中， 再从句对中等概率取一联，长诗不会挤占短诗的出现机会。

摘句多选写成 /line/shanshui,zhiwu，同样支持 n。

摘句统一返回 JSON，正文、句对位置和 poem 基本信息都在同一个对象中。 为了保证结构不丢失，摘句模式下即使 URL 写成 .txt 也返回 application/json； 普通分类的 .txt 仍只返回正文。

动态接口返回 Cache-Control: no-store，连续调用不会复用旧随机结果； /data/* 静态分片仍使用长缓存。本页与分类浏览页本身就是静态文件， 由 CDN 直接返回、不执行后端函数，因此打开文档页不占用任何调用额度。

接口按客户端 IP 限流：同一 IP 每 60 秒最多 60 次请求，平均约每秒 1 次，允许短时突发。 这是 Cloudflare 原生近似限流，按机房分别计数。超限返回 429， Retry-After: 60 秒；CORS 预检请求不计数。

示例：直接嵌入网页

<div id="poem"></div>
<script>
fetch("BASE/shanshui,lushan.json")
  .then(r => r.json())
  .then(d => {
    document.getElementById("poem").textContent =
      d.content + " —— " + d.author + "《" + d.origin + "》";
  });
</script>

06精度与可信度

题材采用「规则 + 语义模型」混合判定：高置信规则保留，已验证的弱类由 DeepSeek 重判， 低置信分歧再由 v4-pro 终审。

方案top-1 准确率说明
关键词规则83.6%稳定、可解释，但弱类边界较粗
DeepSeek 单模型76.4%–76.9%语义理解较好，但常见题材不如规则稳定
混合策略87.2%规则保底 + 弱类语义重判 + 低置信终审

测法：以《唐诗三百首》《宋词三百首》的人工标签为金标准，按 UID 精确对齐 195 首， 比较 top-1 命中率。样本不大，但可复现（tools/eval_llm.py）， 排序与相对提升比绝对数值更值得参考。

theme_conf 是最终采用来源的置信度，规则与模型来源不同，数值不宜直接横向比较； 接口不提供按置信度过滤的参数，每类始终返回全部符合条件的诗词。

09判定说明

21 题材与 v1 意象分类采用两套方法，互不混淆。

分类判定方式
21 题材高置信规则 + DeepSeek 弱类重判 + 低置信 v4-pro 终审；送别/寄赠、哲理/佛道、应制与咏怀等边界均按标题事由和全篇主旨判定
v1 意象分类「意象词典 + 阈值」，规则见 tagger/categories.py
关键词权重越宽泛的词权重越低（如「风」0.5、「月」0.7），需组合达到阈值才算命中
标题加权与强制标题命中权重更高；植物 / 动物 / 食物类要求标题命中，避免正文随手取景造成误判
宋词词牌词牌只表示曲调，不作为事由标题，也不参与标题题材规则

已知局限：意象分类仍有同形歧义（如「芙蓉」兼指荷与木芙蓉）；题材分类在长诗和高度程式化文本上仍有边界误差。 若发现明显错判，可在规则表调整权重或复查对应模型的标注。
